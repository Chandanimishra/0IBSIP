# Iris Flower Classification
By Chandani Mishra - OIBSIP Data Science Intern

Dataset: Iris Flower dataset from sklearn - 150 samples, 4 features, 3 species.

Work done:
- Loaded data, checked shape, null values, statistics
- EDA: pairplot, boxplot for feature distribution
- Train-test split 80-20
- Trained Logistic Regression - 100% accuracy
- Also trained Random Forest
- Confusion matrix and classification report

Tech: Python, Pandas, Matplotlib, Seaborn, Scikit-learn
